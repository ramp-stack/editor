================================================================================
  src/components/scroll.rs
================================================================================
  Momentum scroll physics for one axis. Used for both V and H scroll.

  struct ScrollAxis (Default)
    offset:   f32    [current scroll position in px]
    velocity: f32    [current momentum in px/tick]

    fn push(delta, max_speed)
      Adds delta to velocity, clamps to [-max_speed, max_speed].
      Call from scroll events to accumulate impulse.

    fn set_intent(vel)
      Overwrite velocity directly (sustained drive: key held, drag edge).

    fn tick(friction, max_offset) -> bool
      Advance one frame: offset += velocity, decay velocity by friction,
      kill velocity at boundaries. Returns true if offset moved.

    fn jump_to(pos, max_offset)
      Instant position set, zeroes velocity.

    fn reset()
      Sets offset=0 and velocity=0.

================================================================================
  src/logic/editor_obj.rs
================================================================================
  on_update loop: scroll physics, text rendering, selection overlays, cursor.
  Registered via Editor::register_callbacks -> logic::editor_obj::register.

  fn register(cv, ed)
    Registers one on_update callback. Each tick:
      1. Update background size/color
      2. Image mode: call image_view::update + show, hide overlays, return early
      3. Autosave timer (AUTOSAVE_INTERVAL_SECS)
      4. Recompute max_line_width if zero (on file open or settings change)
      5. Apply scroll_intent to v_scroll.velocity if non-zero
      6. v_scroll.tick(friction, v_max)  — vertical momentum
      7. h_scroll.tick(friction, h_max)  — horizontal momentum
      8. Compute slice_start, text_top from scroll offset
      9. Drag cursor update (while dragging == true)
     10. build_text_slice + build_gutter_slice for visible rows
     11. Update code_text and gutter GameObjects (position + drawable)
     12. selection::overlay_rects -> update SEL_OVERLAY_COUNT pool objects
     13. Cursor blink timer, cursor position, cursor visibility

================================================================================
  src/logic/input.rs
================================================================================
  All input event handlers.
  Registered via Editor::register_callbacks -> logic::input::register.

  fn register(cv, ed)
    Calls all four sub-registrations below.

  fn register_keys(cv, ed)
    on_key_press:
      Guard: mouse must be inside editor bounds.
      Resets idle_timer, blink_timer, cursor_vis.
      Ctrl combos -> handle_ctrl_key()
      Bare/Shift keys:
        ArrowUp/Down   — move cursor, set scroll_intent when cursor at edge
        ArrowLeft/Right — move cursor, clear scroll_intent
        Home/End       — jump to line start/end, extend selection if Shift
        Space          — insert space
        Enter          — smart indent, detect pair (e.g. {} -> newline+indent)
        Delete/Backspace — auto-pair aware deletion
        Tab            — insert 4 spaces
        Character      — insert char, auto-pair close insertion

  fn handle_ctrl_key(key, shift, state)
    s: save    z: undo/redo (stub)    c: copy    x: cut (stub)
    v: paste (stub)    a: select all    /: toggle line comment
    Home/End: jump to document start/end

  fn register_mouse_press(cv, ed)
    on_mouse_press (Left only, inside bounds):
      Resets idle/blink timers.
      Computes row/col from mouse position + scroll.
      Sets cursor, sets sel_anchor = sel_active = (row, col).
      Sets dragging = true.

  fn register_mouse_move(cv, ed)
    on_mouse_move (only when dragging):
      Above editor: sets v_scroll.velocity + scroll_intent (proportional overshoot)
      Below editor: same but positive direction
      Inside editor at edge row: sets scroll_intent for sustained scroll
      Inside editor mid-viewport: clears scroll_intent
      Updates cursor_row/col and sel_active from clamped mouse position.

  fn register_mouse_release(cv, ed)
    on_mouse_release (Left only):
      Sets dragging = false.
      Kills v_scroll.velocity and scroll_intent.

  fn register_mouse_scroll(cv, ed)
    on_mouse_scroll (inside bounds only):
      dy != 0: v_scroll.push(dy * scroll_accel, scroll_max)
      dx != 0: h_scroll.push(dx * scroll_accel, scroll_max), respects h_max boundary

================================================================================
  src/objects/editor_obj.rs
================================================================================
  Initial GameObject creation. Called once during Editor::mount.

  fn setup(cv, ed)
    Creates (in layer order):
      layer 0  — bg            solid background rect (tint_overlay)
      layer 1  — {id}_img      image view (hidden if text mode)
      layer 1  — code_text     Text drawable, clipped to code area
      layer 2  — gutter_bg     solid gutter background rect
      layer 2  — sel_{0..79}   selection highlight overlay pool (hidden)
      layer 3  — gutter        Text drawable, right-aligned line numbers
      layer 4  — cursor        cursor rect (Line/Block/Underline image)

    Also pre-computes max_line_width from the longest line at load time.

================================================================================
  SCROLL FLOW (how a scroll event becomes a reposition)
================================================================================

  on_mouse_scroll fires
    -> state.push_scroll(dy * scroll_speed, scroll_speed_max)
       [adds to scroll_velocity, caps at scroll_speed_max]

  on_update fires every tick (~60 Hz)
    -> state.tick_scroll(scroll_friction)
       [scroll_y += scroll_velocity; velocity *= friction; returns true if moved]
    -> if moved: Explorer::reposition_rows()
       [moves all row GameObjects by Y offset only, no SVG rebuild]

  ConnectorRenderer::reposition_all (inside reposition_rows)
    -> per-segment Y update only (each segment is row_height tall)
    -> clip rect stays fixed to panel bounds

================================================================================
  CONNECTOR LINE ARCHITECTURE
================================================================================

  One GameObject per ROW per connector group (not one per group).
  Each object is exactly row_height px tall.
  Two SVG images shared across all segments:
    straight  — vertical bar, used for non-final rows in a group
    corner    — vertical to mid-row then rounded turn right, used for last row
  On scroll: only obj.position.y changes. No SVG, no image reload.
